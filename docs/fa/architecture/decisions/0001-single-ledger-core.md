# ADR 0001: یک هسته‌ی مالی مستقل از فریم‌ورک

[English](../../../architecture/decisions/0001-single-ledger-core.md) · **فارسی**

**وضعیت:** پذیرفته‌شده

**زمینه.** محصول باید هم به‌شکل داشبورد کار کند و هم به‌شکل موتوری که اپلیکیشن‌های دیگر درون خود به کار
می‌برند. منطق مالی تکراری (یک نسخه در UI، یکی در API، یکی در worker) منبع کلاسیک دفترهایی است که با خودشان
تناقض دارند.

**تصمیم.** همه‌ی قوانین پول در `packages/ledger-core` (`waltrix_core`) زندگی می‌کنند. این پکیج به SQLAlchemy
و PostgreSQL وابسته است، نه به FastAPI. هر use case نویسنده تراکنش دیتابیس خودش را دارد. API یک آداپتور
نازک است؛ داشبورد فقط از REST API عمومی و از طریق SDK تایپ‌اسکریپت استفاده می‌کند.

**پیامدها.** یک اپلیکیشن پایتونی میزبان می‌تواند مستقیم `waltrix_core.services.operations.transfer` را صدا
بزند و دقیقاً همان تضمین‌ها را بگیرد. لایه‌ی API کوچک و کسل‌کننده می‌ماند. هسته نمی‌تواند از ابزارهای
وابسته به درخواستِ یک فریم‌ورک وب استفاده کند، پس هویت انجام‌دهنده صریحاً به‌شکل `Actor` پاس داده می‌شود.
